# Frozen1000 - GitHub Pages mockup

Static mockup for presenting the Frozen1000 landing page direction.

## How to open locally

Open `index.html` in a browser or serve this folder with any static server.

## Structure

- `index.html`: complete static landing page markup.
- `assets/css/styles.css`: documented brand tokens, layout rules, section components, motion, and responsive behavior.
- `assets/js/app.js`: documented drawer navigation, reveal animation, and demo tracking.
- `assets/brand/`: horizontal and vertical Frozen1000 logos.
- `assets/products/`: product images used by the hero, category cards, and social preview.
